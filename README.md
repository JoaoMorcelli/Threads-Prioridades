# Threads-Prioridades
Neste branch, foi colocada uma interrupção (botão) que tem como objetivo, quando acionado, de acender um LED azul, interrompendo a sequência definida pelas prioridades dos Threads.

Para testar, clone o código em seu VSCode, pressione o botão e veja se o que acontece é o esperado. Em caso positivo, aceite o Pull Request.
